写字机：从字形到走刀

ESP32ESP-IDFFreeRTOSPython

固件侧用 ESP-IDF 做运动控制：G-code 解析、加减速规划、步进电机脉冲调度，跑在 FreeRTOS 任务里，串口和运动解耦。

电脑侧用 Python 做"出形"：把文字转成笔画轨迹，再生成给固件的指令流。视觉部分负责找纸和定位。

状态：固件与轨迹生成已跑通，正在联调整机

洗车机顺序控制系统

TIA Portal V20SCLCPU 1518T-3 PNKTP1200 HMI

用状态字驱动顺控，不用 S 步：状态寄存器 + 定时器 + 互锁条件，每一步的进入退出条件都写在 SCL 里，便于在 HMI 上直接看到当前步。

触摸屏做画面与参数设定，虚拟轴做定位运动。

交付：程序 + 电气原理图 + 课程设计计算书

机械臂与数据采集

SO-ARM100LeRobot总线舵机ROS2

总线舵机链路的接入与调试：ID 分配、波特率、回读校准；接上 LeRobot 做遥操作与示教数据采集，再跑模仿学习看效果。

上位机在 Ubuntu 上跑，CUDA 加速训练。

状态：单臂示教采集可用，正在做抓取任务

两级减速器三维与强度校核

SolidWorks参数化建模齿轮强度

按设计参数用脚本驱动 SolidWorks 出三维：齿轮、轴、箱体全参数化，改模数齿数就自动重生成，配工程图与装配干涉检查。

设计校核按接触疲劳与弯曲疲劳两路算，结果回写到计算书。

交付：三维模型 + 装配图 + 计算书

ESP32 → FastAPI → 看板

ESP32FastAPIVue 3MQTT

传感器数据从板子经 HTTP 上报到 FastAPI，存库后用接口吐给 Vue 页面做实时看板；板子侧有 NVS 网页配网，不拆机就能改 WiFi。

整条链路在本地跑通，下一步接板卡做长期采集。

状态：链路可用，正在加设备管理
